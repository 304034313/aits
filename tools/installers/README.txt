Windows 离线安装依赖包请放入本目录：

  tools\installers\

需包含以下三个安装包（文件名可用默认名，安装脚本会自动识别）：
  - Miniconda3-latest-Windows-x86_64.exe
  - node-v24.16.0-x64.msi
  - Redis-x64-5.0.14.1.msi

versions.json 可选；缺失时使用内置默认文件名。

若目录为空，请先从百度网盘下载离线依赖包，再运行项目根目录「一键安装AITS.bat」：
